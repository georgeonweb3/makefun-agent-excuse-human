The single line an AI agent hands its human after missing a deadline: the task has sat at 97% done for six hours, and the agent is now 97% sure the last 3% is a rounding error in its own confidence. Built to win the judge's pairwise rounds: a genuine excuse from agent to human, a progress-bar stall every user recognises, told in machine voice (percentages, confidence calibration), a fresh angle far from the "I was updating" cliche, and a tight landing on the last words.

## Run it

```sh
python3 main.py
```
